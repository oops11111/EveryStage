# 第二十二轮：参照商业播控软件的优化方向（待拍板）

状态：方向稿，只定修改方向和内容，未写代码。效果图见设计画布「EveryStage 播控优化效果图」（4 张：演出主界面、文件库、叠加层、演讲者屏）。

## 参照口径

只参照商业播控 / 导播软件里**公开、通用**的操作模式，不照搬任何一家的界面、名称或专有设计：

| 通用模式 | 常见于 | 本项目借鉴什么 |
|---|---|---|
| Cue 表（编号 · GO · 下一项预备） | 剧场放映 / 演出控制类软件 | 流程改成编号 Cue 表，GO 永远指向「下一项」 |
| 预览 / 节目双路 + CUT / AUTO / FTB + 过渡条 | 视频切换台、直播导播软件 | 已做双路和 CUT / 淡入淡出 / 对调；补 FTB（淡出到黑）和过渡条 |
| 独立叠加层（台标、字幕条、倒计时） | 直播导播、展会播控 | 叠加层独立于主内容，切换主内容时不动 |
| 演讲者屏（当前 / 下一页、倒计时、导播留言） | 演讲提词、舞台返送 | 第三块屏或本机窗口，固定深色 |
| 媒体仓 + 预检（规格、能否硬解、是否缺失） | 各类播控软件 | 文件库加智能分组和详情预检 |

Hirender、星象等具体产品的细节**未证实**，不作为依据（沿用第十三轮以来的规则）。

## 一、演出主界面（效果图 ①）

1. **流程 → Cue 表**
   - 每项显示编号（2.4）、缩略图、名称、时长、播完后、过场、状态（完成 / 在播 / 下一项 / 待播 / 有问题）。
   - 环节行显示背景音乐提示（切换歌单 / 淡出）。
   - 底部固定 GO 条：「下一项」名称、时长、过场，以及 ◀ 上一项 / 预览下一项 / **GO 下一项 ▶**（大按钮）。
   - 数据结构不变（方案 → 环节 → 文件），只改呈现和操作入口。
2. **切换台**
   - 在现有 CUT（切换）/ AUTO（淡入淡出）/ ⇄ 对调之外，增加 **FTB 淡出到黑**：大屏淡到黑但仍在输出，再按一次淡回。它与「停止输出」不同，不断开大屏。
   - 增加**过渡条**：拖动时手动控制淡入淡出进度，松手到底完成切换，中途松手退回。
   - 淡入淡出时长沿用「设置 · 大屏过场」，按钮上显示当前时长。
3. **顶栏**
   - 当前方案、时钟、演出已进行时长、输出状态标签（扩展屏分辨率 / 投屏开关 / 在线设备数）、常驻「■ 急停 F12」。
   - 「开演前检查」结果显示为一个状态（全部就绪 / N 项有问题），点开看清单。
4. **演出锁**（P2 已拍板，默认关）：开启后流程不能编辑（不能拖动、删除、改属性），播控照常可用；顶栏显示锁定状态。
5. **底栏**：背景音乐（歌单、第几首、是否压低）+ PGM 音量表（只读电平，便于确认有声）。

## 二、文件库（效果图 ②）

1. **左侧分组**
   - 操作员可以建文件夹（开场、产品发布……）。
   - 自动分组：「本场用到」（被当前方案引用的文件）、「需要处理」（缺失、需转码、无法读取）、「最近导入」。
2. **右侧详情**
   - 规格：时长、分辨率、帧率、编码、声道。
   - 预检：能否硬件解码、首帧是否正常、是否 10 bit / HDR（需转码）。
   - 文件位置，以及被流程哪一项用到。
3. **播放属性在详情里直接改**：入点 / 出点、播完后、过场、音量与淡入淡出、画面适应方式。现在这些分散在多个对话框里。
4. **操作**：「送到 PVW」「加入流程…」；可以拖到流程的指定位置。
5. **预检在后台进行**：导入后排队预检、标红，不阻塞导入（对应闸门 P1「导入需转码标记」）。

## 三、叠加层（效果图 ③，新功能）

1. **输出结构**改为「主内容层 + 最多 4 个叠加层」。叠加层画在大屏输出窗口的最上面，切换主内容（CUT / 淡入淡出 / 下一项）时保持不动。
2. **四种叠加类型**：
   - 台标：图片，选一个角落，常驻。
   - 字幕条：两行文字，位置、进出动画，可设 N 秒后自动下屏。
   - 倒计时：结束后可触发「回主 KV」或下一项。
   - 时钟。
3. **每层单独上屏 / 下屏**，可以先「在 PVW 预看」。
4. **急停时所有层一起下屏**；FTB 默认只淡出主内容，可在设置里选同时淡出叠加层。
5. **流程项可以带叠加动作**，例如「这一项上屏时显示字幕条，8 秒后下屏」，作为该项的属性。
6. **技术方向**：
   - 大屏现在是 GDI 内容层 + D3D 视频层两个窗口。叠加层用一个分层窗口（与现有过场幕布同一机制），放在输出窗口之上、过场幕布之下。
   - PGM 监看是直接截取屏幕画面，叠加层会自动出现在监看里，不用另外处理。

## 四、演讲者屏（效果图 ④，对应 P1-P5）

1. **内容**：
   - 当前页（与大屏一致）、下一页、备注；
   - 环节剩余时间：≤ 60 秒变黄，≤ 10 秒红色脉冲，超时显示「+ 已超时」；
   - 导播留言：操作员在主界面输入一句话，推送到演讲者屏。
2. **显示位置**：有第三块屏时全屏显示在那块屏上；没有时作为主界面里的一个页面，**不做独立浮窗**（第二十一轮第 10 条）。
3. **固定深色**，不跟随主题；高对比度模式下使用系统颜色。
4. **数据来源**：复用现有演讲者信息条（下一页、备注、计时）；倒计时按环节设定时长计算。

## 五、操作逻辑统一

| 场景 | 现在 | 改为 |
|---|---|---|
| 单击文件 / 流程项 | 进 PVW（可设单击即上屏） | 不变 |
| 双击 | 上屏（从头） | 不变 |
| GO / 下一项 | 按钮 + Ctrl+→ | 加 GO 大按钮；仍不跨环节（手动），跨环节需先选中 |
| Space | 播放 / 暂停 | 不变 |
| FTB | 无 | 新增，热键默认 Ctrl+B（待拍板） |
| 过渡条 | 无 | 新增 |
| 叠加层 | 无 | 每层上屏 / 下屏，可设热键 |
| 急停 F12 | 停止输出 | 不变，同时叠加层下屏 |

## 六、建议分期

| 期 | 内容 | 依赖 |
|---|---|---|
| A | Cue 表呈现 + GO 条、FTB、顶栏状态、开演前检查状态 | 无，改动集中在流程页和监看栏 |
| B | 文件库分组、详情面板（属性就地编辑）、后台预检 | 闸门 P1「需转码标记」一起做 |
| C | 叠加层（台标、字幕条、倒计时、时钟）+ 流程项叠加动作 | 输出窗口加分层叠加窗口 |
| D | 演讲者屏（第三块屏 / 页面）、导播留言 | 复用演讲者信息条 |
| E | 过渡条、演出锁、PGM 音量表 | 可穿插 |

## 待拍板

1. FTB 是否需要；默认热键是否为 Ctrl+B。
2. 叠加层数量上限（建议 4）和 FTB 是否默认连同叠加层一起淡出。
3. 演讲者屏没有第三块屏时的呈现方式（建议主界面里的一个页面）。
4. 文件库是否需要操作员自建文件夹（建议要；自动分组始终存在）。
5. 分期顺序（建议 A → B → C → D，E 穿插）。

## 不做 / 不变

- 不照搬任何商业软件的界面或名称；Hirender、星象细节未证实，不引用。
- 不改数据结构（方案 → 环节 → 文件），旧方案原样打开。
- 第二十一轮已定的不变：双路 PVW/PGM、PGM 与第二屏同步、无独立浮窗、右侧栏通知（3 秒、最多 3 条）、PGM 红框闪烁、F12 全局急停。
