## B-15 验收项

| 编号 | 验收项 | 操作摘要 | 通过标准 | 结果 | 证据文件 | 备注 |
|---|---|---|---|---|---|---|
| B15-01 | 首次配对数字比对 | Caster A 选择 Terminal 并开始投屏 | 两端显示同一组 6 位数字；Terminal 接受后 Caster 保存 v2 密钥 |  |  |  |
| B15-02 | 报文不含明文密钥 | 抓首次配对 UDP 47990 包，查看 `pair_response` | 只有 `KeyConfirmation`；没有 `PairingKey` 字段和 32 字节 base64 明文密钥 |  |  |  |
| B15-03 | 已配对直连 | 重启 Caster A 后再次开始投屏同一 Terminal | 不再弹配对框；设备先进设备源窗口预览，不直接顶掉大屏 |  |  |  |
| B15-04 | 设备窗口预览 | 设备连接后不按「投屏」 | 设备源窗口直接显示视频预览；预览静音；大屏保持原内容 |  |  |  |
| B15-05 | 投屏上大屏 | 大屏先播放本地内容；设备预览中按「投屏」 | 设备画面上大屏；上大屏后才出声；设备卡片显示大屏输出中 |  |  |  |
| B15-06 | 回退恢复图片/视频位置 | 投屏前大屏播放图片或视频指定位置；按「回退」 | 恢复同一文件、同一播放位置/暂停状态；设备仍留在设备源窗口 |  |  |  |
| B15-07 | 回退恢复 PDF/PPT 页 | 投屏前大屏播放 PDF/PPT 指定页；按「回退」 | 恢复同一文档、同一页/放映状态；设备仍留在设备源窗口 |  |  |  |
| B15-08 | 设备断开恢复 | 设备正在大屏输出时停止 Caster 或断网 | 大屏按回退点恢复；Terminal 不崩溃；设备源窗口回到等待/断开状态 |  |  |  |
| B15-09 | 第二台设备拒绝 | A 已连接时 B 发起投屏，Terminal 拒绝 | B 先收到 Pending，最终被拒绝；A 不受影响 |  |  |  |
| B15-10 | 第二台设备接受 | A 已连接时 B 发起投屏，Terminal 接受 | A 按断开流程恢复；B 只进入预览，仍需按「投屏」才上大屏 |  |  |  |
| B15-11 | 同设备重连 | 同一 Caster 切换显示器或重启会话 | 不弹二次确认；若原来在大屏，新会话直接接回大屏，回退点沿用 |  |  |  |
| B15-12 | 投屏开关关闭期间新请求 | 关闭 Terminal 投屏开关后让 Caster 请求投屏 | 网络 Caster 仍可进入设备源窗口预览 |  |  |  |
| B15-13 | 投屏开关关闭时收回设备流 | 设备已上大屏时关闭投屏开关 | 设备退回静音预览且不被断开；大屏恢复设备投屏前内容或空闲状态 |  |  |  |
| B15-14 | 本地 Program 输出受投屏开关管理 | 本地内容正在 Program 时关闭投屏开关 | 本地 Program 输出被收回并恢复扩展屏原状态 |  |  |  |
| B15-15 | 操作屏位置：主窗口可见 | 主窗口可见时触发配对框和第二设备确认框 | 弹框在主窗口所在操作屏，不出现在观众扩展屏 |  |  |  |
| B15-16 | 操作屏位置：主窗口隐藏/最小化 | 主窗口隐藏或最小化时触发确认框 | 弹框在操作屏；扩展屏为主屏时也不弹到观众屏 |  |  |  |
| B15-17 | 旧 Caster 请求新 Terminal | 用旧版 Caster 请求新版 Terminal | 旧 Caster 显示「投屏机程序版本过旧，请更新后重新配对」 |  |  |  |
