# EveryStage 0.9.3 内部安装与使用

本轮在0.9.2之后新增真正演讲者缩略图平滑定位，以及软件内PPT过渡的FluidMotion定时轨迹；保留既有操作与效果算法。安装包为内部未签名Windows x64应用，正式交付依据最终离线目录的ROOT_ACCEPTANCE.json；当前源码检查点不等于已完成发布。

安装前先校验交付SHA256SUMS/VERIFY.ps1，再由使用者自行决定是否运行安装器。退出正在运行的EveryStage应使用托盘“退出”，关闭主窗只会隐藏。默认安装终端机，可选择投屏端或两者；卸载默认保留配置，/DELETEDATA=1删除配置但保留日志。不要把自动验收脚本用在用户现有安装上。升级验证只覆盖已归档0.9.1→0.9.3，没有扩大降级/历史版本兼容性声明。

PPT软件过渡：设置→PPT翻页过场→统一过场（推荐），选择效果、方向和时长，下次翻页生效。三种效果、四方向保持原行为；系统减少动画偏好仅读取，开启时立即显示目标。Office/WPS自己的原生动画策略不被此轨迹替换。

演讲者视图：正在大屏原生放映时自动打开，或通过状态栏按钮打开。←/→/空格保持既有行为；缩略图滚轮、键盘和当前页自动定位平滑，按下拖拽立即接管并中断动画。没有扩展屏时现有策略为静态幻灯片。此次隔离控件测试使用合成页面，不等于已验证真实Office许可、现场文稿、大屏设备或性能。

0.9.2封存目录与原组件包不覆盖。0.1.0包内candidate说明是构建时状态，最终外部签认只接受同一已测字节，不重写产品。GitHub制品实际保留上限3天，离线交付保存原升级基线；所有云端副本过期时CI停止，不能假称长期可下载。现有第三方元数据及可获得notice随包交付，缺失上游嵌入notice仍为披露限制。
