# 旧 HTML 原型（早期概念稿，仅作历史参考）

本目录里是 EveryStage 早期用 HTML 做的界面原型：

- caster_ui_prototype.html
- terminal_ui_activity_concept.html
- terminal_ui_devices_concept.html
- terminal_ui_prototype.html
- terminal_ui_settings_concept.html

这些原型停留在概念阶段，与当前实现已经脱节：现在的终端是流程页编排、PVW/PGM 双监看、背景音乐条这一套界面，原型里的页面结构和控件构成都对不上。保留它们只是留个历史痕迹，不要按原型理解当前产品，更不要拿它做验收依据。

当前界面的事实源是仓库代码本身（src/Terminal、src/Caster 的 UI 代码），界面改版的计划与效果图见 docs/OPTIMIZATION-PLAN-R22.md。
